Questions people ask

Which state page should I open?

Open the state where you live. Each page lists the SHIP counseling program from shiphelp.org and the Medicaid agency from Medicaid.gov.

Do these pages list private premiums?

No. Federal rules that do not change by state are linked. Private plan names and premiums are not listed.
